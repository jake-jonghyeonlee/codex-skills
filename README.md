# Codex Skills

Codex 앱에서 사용 가능한 코드 이해 + 감사 스킬 4종.

## 포함 스킬

| 스킬 | 용도 | 산출물 |
|------|------|--------|
| **code-map** | 레포 구조 파악 — 모듈·심볼·의존관계 | HTML 대시보드 |
| **code-flow** | 데이터 흐름 시각화 — 프로젝트 유형 자동 감지 | HTML 다이어그램 |
| **code-arch** | 아키텍처 다이어그램 — 계층·횡단 관심사·확장 포인트 | HTML 다이어그램 |
| **code-audit** | 코드 감사 리포트 | HTML 대시보드 |

## 사용법

이 레포를 분석 대상 프로젝트에 복사하거나, Codex 앱 태스크에서 참조합니다.

```sh
# 대상 프로젝트에 복사
cp -r .codex/ /path/to/target-project/
```

`.codex/skills/` 디렉터리가 프로젝트 루트에 있으면 Codex가 자동으로 인식합니다.
